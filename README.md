# Tushare 本地数据采集工作台

面向 Windows 的独立金融数据采集器。EXE 启动 localhost 服务，在浏览器中查看计划、日志、历史覆盖和数据预览，无需 Docker。

## 功能

- 根据随附目录生成全量历史计划，显示可执行、等待目录、待确认和排除项目。
- 自动处理证券目录依赖；排除已配置的本地重复行情和普通股票资金流。
- 历史分片、顺序定位首个非空区间；支持区间缩小和可靠分页。
- SQLite 断点、有限重试和持久化限频；重启默认暂停。
- 暂停后选择其他项目续采，或手动切换主/备用 Token；不自动轮换账号绕过限流。
- 全局上限 400/min，同时遵守接口更低频次及代理 IP 冷却，实际速度可能显著低于该上限。
- 可恢复错误最多三次总尝试；权限、参数、校验和写盘错误立即暂停。
- 非空结果原子保存到中文分类目录，空结果只记核验断点，不生成空 JSON。

## 数据源与账号

当前适配 Tushare 兼容代理，地址见界面及 `源码/core.py` 的 `PROXY_URL`，不自动回退官方直连或其他供应商。仓库不提供账号或数据订阅。

首次运行后在本机页面输入自己的主/备用 Token。凭据使用当前 Windows 用户的 DPAPI 加密保存于本机状态数据库，不进入 Git。不要在源码、文档或示例中填写真实凭据。

积分不等于全部独立权限。代理还可能有独立字段和 IP 限制。股票列表目前只保存已验证的代码、名称两列，其他基础属性未采集；接口目录不保证均已获权。

## 运行

建议 Python 3.11+，当前在 Windows / Python 3.14 验证。应用运行仅依赖 Python 标准库。

```powershell
python .\源码\app.py
```

默认端口 `127.0.0.1:18793`。请使用启动时自动打开的完整地址，其中包含本次本地访问令牌，不要分享。

1. 加密保存账号。
2. 选择历史范围及已确认的权限/本地覆盖，生成全量计划。
3. 查看逐项报告，点击开始采集。
4. 暂停且当前请求结束后可切换项目。结束时点击“暂停并安全关闭”；关闭浏览器不会停止服务。

## 构建 EXE

```powershell
.\构建.ps1
```

脚本在本项目中建立构建环境并安装 `requirements-build.txt`；可通过 `-Python` 指定解释器。输出 `Tushare数据采集器/Tushare数据采集器.exe`，构建后可双击 `启动Tushare采集器.cmd`。

## 验证

```powershell
python -m unittest discover -s .\源码 -p test_app.py
```

单元测试使用临时目录和模拟服务，不调用真实数据接口。`源码/test_ui.cjs` 是可选 Playwright 页面验证，需要 Node.js、Playwright、Edge 和本机已启动的采集器；操作请求会被拦截，不启动真实采集。

## 本机文件

| 内容 | 默认位置 |
| --- | --- |
| 数据 | `D:/Free_stockdb/stockdb/mydb/Tushare/分类/中文项目名/` |
| 状态、断点及加密账号 | 项目目录 `状态/采集状态.sqlite` |
| 当前本机服务信息 | 项目目录 `状态/当前服务.json` |
| 构建环境和临时文件 | 项目目录 `构建环境/`、`构建临时/` |

数据路径目前在 `源码/core.py` 配置，更换部署位置时应先调整。浏览器自身缓存由浏览器管理。

## 仓库边界与限制

仅上传源码、接口元数据、脚本、测试和文档；账号、状态、数据、日志、截图、浏览器配置及构建产物全部忽略。详细说明见 [使用说明](使用说明.md)。

“完成”表示当前查询方式已走完，不保证上游历史绝对完整。发现的最早日期限于所设范围及代理实际返回；快照接口不能恢复过去状态。连续空结果、分页不可确认或代理异常时暂停等待核验。

## Ubuntu 24.04 云端版本

[Linux独立版本](linux/README.md)保存在 `linux/`：保留同类网页面板，支持双Token领取不同任务、30秒起持续重试、独立权限接口排除、任务级错误隔离及systemd常驻运行。Windows版规则保持独立。

Linux部署包在本机独立交付目录生成，并可携带经核验的Windows任务基线，从已提交断点继续采集。基线、目录缓存、实际数据及编译产物均不上传本仓库；源码重建的通用包需要自行配置或导入进度。
